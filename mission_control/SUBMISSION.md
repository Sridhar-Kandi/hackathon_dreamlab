# Presentation checklist

- Start the console from the repository interpreter and run the stock-scene probe.
- Open the fresh successful sequence and check both step outcomes, the event order and the camera playback.
- Open the fresh timeout sequence and check that the second step was unreached.
- Confirm the run source before presenting its outcome. Scripted runs use local MuJoCo physics and a scripted controller.
- Keep the original run export available. Fine-tuning and paid Dream-1 runs remain deferred.
